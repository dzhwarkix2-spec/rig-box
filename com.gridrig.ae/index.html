Guides + bounding box. One click.

  1. Select the text or artwork layer you want to frame.
  2. Click Create Rig.
  3. Animate Master Reveal, each line’s Start / End, or Boundary - End in AE.

Two vertical and two horizontal lines extend a short distance past the box. Use Horizontal Extension and Vertical Extension to change their length in pixels. A separate closed rectangle and four corner markers frame your artwork. Set Guide Opacity to 0 to see the box on its own.

Change Frame Width %, Frame Height % or Guide Offset in Effect Controls to resize the frame. Animate the controller’s Position to move it.

Select a rig from an earlier bundle and click Create Rig to apply short line extensions while preserving its box and controller keyframes. Existing guide keyframes are kept.

Use a tightly cropped precomp to frame several elements together. 2D layers only. Generated lines render in exports.
